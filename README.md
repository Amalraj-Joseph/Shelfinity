# Shelfinity
A smart and scalable Library Management System built to simplify book tracking, lending, and user management.

[![Open Issues](https://img.shields.io/static/v1?label=open%20issues&message=click%20to%20view&color=blue)](https://github.com/shadow-codex/Shelfinity/issues)
![License](https://img.shields.io/badge/License-MIT-blue.svg)

## 📦 Project Structure
```
Shelfinity/ 
├── backend/             # APIs, DB models, and server logic 
├── frontend/            # UI components and frontend logic 
├── docs/                # Architecture, setup guides, and diagrams 
├── scripts/             # Helper scripts (e.g., data migration, setup) 
├── .github/ │ 
  └── workflows/         # GitHub Actions CI/CD files 
  └── ISSUE_TEMPLATE/    # Templates for issues and PRs
├── README.md 
├── LICENSE
└── .gitignore
```

## 🚀 Getting Started

### Prerequisites
- React
- Jakarta EE
- Docker 

### Clone the Repository
```
git clone https://github.com/Shadow-Codex/Shelfinity.git
cd Shelfinity
```


## 🔧 Development Setup

### Backend

